# Clock Out! 动物班车

已集成到 tapmelo 网站，源游戏仍可独立本地试玩。网站入口为 `/games/marble-sort/` 和 `/hi/games/marble-sort/`，附四篇英印双语攻略。未接入广告或游戏遥测。完整网站由 `../site/scripts/build.mjs` 构建，同步白名单见 `../site/scripts/sync-marble.mjs`。

## 本地试玩

在本目录执行 `npm run serve`，打开 <http://127.0.0.1:4188>。无构建步骤，不依赖 CDN。默认英语，`?lang=hi` 切换印地语；未识别的语言回退英语。

## 当前规则

- 全部 60 关基础容量固定 **27 格**。每局一次的扩容道具仍增加 9 格。
- 点击前排料盒放出 9 颗球。大多数是单色盒，少量双色盒含 6＋3 颗。
- 四列班车各自排队，收满 3 位同色乘客后发车，仅由本列下一辆车补位。
- 目标颜色可能被同列前方料盒挡住；问号盒移到最前排时揭晓。
- **满载不立即失败**：带上仍有球可以进入当前盒子，或满盒正在退场补位时，继续等待。只有传送带已满、入口有球等待、当前没有上车或换车机会，而且这种状态持续到上车交接结束后，才判定堵塞。
- 底部保留撤回和扩容，可暂停、重开、撤回一次、切换 2 倍速度。清空小屋且最后一位动物进入环道后自动以 4 倍速收尾。
- 键盘 1–5 放球，页面空白处按空格暂停；最高解锁关、引导完成状态和设置保存在本机。

## 当前关卡和界面

第一关有 3 种颜色和 6 间单色小屋，共 54 位乘客。初次游玩时小狐狸解释放行、上车和车队预览，第一次看到隐藏小屋时另有提示。每列站台显示当前车与最多三辆预览车，头像辅助区分配色。

第 41–60 关使用 12 种颜色。从第 5 关起，每隔两个或三个普通关有一关超难关，共 16 关，各有两处放行顺序陷阱。各关始终可以无道具通关。最终关通关后可重玩第一关，最高解锁记录继续保留。

开始页显示加载状态和当前解锁关。游戏按关卡轮换晴日、雪景、雨景和秋景。发车后有星星飞入进度条，连续发车显示连击。设置可独立切换音效、配乐及支持设备上的震动。

## 结算交互

- 失败时显示放大的“扩容 +9 并继续”和“重试”。扩容每局一次，已使用时只显示重试。
- 成功时显示“下一关”；第 60 关完成后显示“再玩一次”。
- 成功有动物巡游和玩具琴旋律，失败有小狐狸反馈和重试卡片。
- 首次游玩默认开启音效；暂停/帮助内可关闭，保留已保存的偏好。减少动态效果模式取消结算摆动、彩屑和按钮扫光。

## 物理与动画

- 本地 Matter.js 0.20.0 模拟重力、碰撞、摩擦和低幅反弹，固定 120 Hz 步长，并在显示时插值。
- 错峰释放球体，检查出生位置的实际空隙，防止重叠挤飞。掉落球不休眠；仅接触入口挡板的球固定等待，失去支撑的上层球继续下落。
- 料盒内球的消失与刚体生成同步，全部出盒后后排再滑入。开局为短距离错峰入场，撤回不重播整块棋盘入场。
- 传送带底图、漏斗背景和阴影缓存绘制。运动期间画布目标为 60 帧/秒，移动端像素比最高 1.5；传送带位置按物理步长插值。入带时立即随履带前进，仅平滑收拢落点偏移，半径、步态与阴影连续；装盒后轻微回弹，满盒合盖轻移退场，下一盒平滑补位。
- 履带容量和取球为确定性逻辑；出带入盒是表现动画，不是整个游戏都使用刚体模拟。
- 空闲、暂停和页面进入后台时停止循环绘制，缩放时仍会重绘画布。漏斗里没有运动中的乘客时跳过刚体求解。减少动态效果偏好关闭装饰晃动和彩屑，保留必要运动。

## 文件

- `js/levels.js`：40 关编排、混色、隐藏标记、容量和参考路线。
- `js/shift-patterns.js`：六种经过队列排列验证的挑战结构。
- `js/engine.js`：库存、收纳、传送带、堵塞判定和撤回。
- `js/physics.js`：漏斗刚体、出料交接及恢复。
- `js/view.js`：Canvas 绘制、材质和动画。
- `js/app.js`：界面、生命周期、模拟调度、音效和同源网站嵌入。
- `js/i18n.js`：英语／印地语界面、无障碍标签、关卡和颜色名称。
- `vendor/matter.min.js`：Matter.js 0.20.0；许可证见 `vendor/MATTER-LICENSE.txt`。

玩法参考：[Marble Sort 官方 App Store 页面](https://apps.apple.com/us/app/marble-sort-ball-color-puzzle/id6754558455)。界面和绘制资源由本项目实现。

移动端使用完整屏宽；房子、乘客与车辆按颜色配对。传送带每秒前进 0.21 圈，上车 160ms、满车换车 440ms；站台接人范围覆盖短暂换车期间经过的乘客，避免同色连续车重复绕圈。

连续点击同一列会立即打开下一栋房子，掉落仍按物理空间依次排出，避免重叠生成。房子补位动画 180ms；重力由 0.95 调到 1.3，下落速度上限由 5.5 调到 7。传送带入口不再等待固定槽位，接触入口且有间距即可接入；新动物从每秒 0.21 圈平滑加速至每秒 0.66 圈，结合前方动物速度与间距跟随，前方空出后自动恢复快跑。到达左上直道前提前减速，此后以每秒 0.21 圈随带移动，不会在下一圈重复快跑。入口拥挤时短暂让行形成合流间隔，满带仍保留 27 人上限。
