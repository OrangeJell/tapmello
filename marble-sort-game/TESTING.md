## 运行浏览器脚本

先启动 `npm run serve`。从本项目父目录创建 `output/playwright/marble-sort`，各脚本使用独立 Playwright CLI 会话，先打开本地试玩页后执行脚本，例如：

```sh
playwright-cli --session marble-check open http://127.0.0.1:4188/
playwright-cli --session marble-check resize 390 844
playwright-cli --session marble-check run-code "$(cat marble-sort-game/tests/browser-smoke.js)"
```

恢复专项与满载专项分别使用新会话，避免重复安装虚拟时钟。脚本结束时恢复时钟。
