## 规则

- 初始两个收纳盒，每盒三个同色螺丝。螺丝采用十字、斜十字槽口，盒子保留颜色符号辅助辨认。
- 第三个和第四个盒子可以分别领取，按统一队列分配盒色，本局有效。盒子最多四个；失败续局增加一个可接住暂存颜色的盒子。
- 配钉由实际轮廓和安全间距决定，每块至少 1 颗，不设固定数量上限。
- 初始五个暂存孔位。新盒子出现时，暂存螺丝自动归位。
- 拆卸后螺丝平滑飞入目标，暂存螺丝错峰归位并平滑补位；满盒依次落定、回弹、合盖弹出，新盒随后补位。动画期间可以继续拆卸其他可用螺丝，暂停与重开会同步暂停或取消收纳动效和完成音效。
- **暂存孔位全部填满立即卡关**。盒子不足四个时，可增加盒子从失败现场继续；四个盒子都解锁后，可逐次增加一个孔位继续，最多七个。只有四个盒子已解锁且七个孔位填满时，卡关才只提示重新开始。
- 加孔位：一次增加一格，上限七格。
- 融玻璃：本局一次。先领取资格，再点选一块高亮玻璃。取消选择保留资格；融化后螺丝保留在原位置。
- 奖励暂未接入广告。每个奖励都先展示说明弹窗，**确认后直接发放，取消不改变状态**。
- 被遮挡的螺丝可以透视看见，但不能拆卸。每块玻璃按局部实际遮挡计算层数，上面没有玻璃压住就是第一层。前四层显示彩色玻璃，螺丝逐层染色、减弱；更深的玻璃只显示没有空孔的虚化阴影轮廓。点击受遮挡的螺丝时，使用轻微明暗反馈并提示先移除上方玻璃，不再播放类似拆卸的抖动。
- 单支点玻璃使用真实铰接约束；摆动与自由落体在同一物理组中联动碰撞，包含支撑、轻微回弹、摩擦和支撑拆除后的继续下落。按实际模拟时长播放，短落程不再强行拉长到一秒。动画不锁住其他可拆螺丝。
- 百分比按已完成装盒计算；棋盘与暂存全部收纳完成后通关。

每关由明确的主题、区域、覆盖链和支撑岛编排。基础形状补充主题板，保留大小混合和原有钉距。增加珍珠白、铜棕两色，后期最多使用十种颜色。先生成真实几何拆解路线，再结合阻挡板释放和收纳盒进度编排颜色；离线筛选多个拆板顺序与贪心反例，运行时不搜索答案。设计与路径报告见 `output/design/level-routes.json`。

## 代码结构

| 模块 | 职责 |
| --- | --- |
| `js/engine.js` | 不依赖页面的纯状态转换、装盒、道具、卡关和数量守恒 |
| `js/geometry.js` | 共享轮廓、重心、摆动、坐标与遮挡 |
| `js/board-view.js` / `js/glass-art.js` | 玻璃与螺丝绘制、深层弱化、实际画面点击校验 |
| `js/collections-view.js` | 按螺丝与盒子批次调度收纳、孔位预留与局部绘制 |
| `js/motion.js` / `js/plate-motion.js` / `js/sound.js` | 可暂停、取消的动画和短音效 |
| `js/app.js` | 生命周期、交互、弹窗、确认奖励、页面嵌入 |
| `js/config.js` | 棋盘大小与道具上限 |
| `js/storage.js` | 偏好、完成进度、通过操作日志重建稳定局面 |
| `js/i18n.js` | 英语 / 印地语 |
| `scripts/level-layouts.mjs` | 主题区域、大小板、配钉、同层支撑与摆动组合 |
| `scripts/generate-levels.mjs` | 确定性配色、配钉检查和合法通关路径生成 |
| `js/level-data.js` / `js/levels.js` | 生成的十五关数据及目录入口 |
| `js/solver.js` | 独立搜索工具，不被游戏页面加载 |
| `js/analytics.js` / `js/telemetry.js` | 复用站点加载、开局、有效操作、卡关和结束统计 |

棋盘复用静止轮廓和玻璃内部采样点，动画中约每 32ms 检查运动玻璃及其扫过区域。玻璃色调使用轻量采样，螺丝遮挡始终检查真实轮廓和完整螺丝头；点击时立即补做检查，并把当前动画姿态交给状态转换和保存日志。已经露出的螺丝无须等待动画结束，盖住的螺丝仍不能穿透拆卸。玻璃按参考图采用较实的彩色面、白色厚边、浅高光和偏移底边。深层显示灰色轮廓，被遮挡的螺丝逐层弱化，前景螺丝使用饱和色、深槽口和轻倒角。极深的玻璃停止绘制，材质不使用逐块模糊滤镜。手机顶部盒子、临时孔和底部按钮压缩高度，操作区尽量占满横向空间，螺丝触控区至少 44px。

旧关卡数据、木质绘制、逐层场景生成器及旧关卡浏览器测试已删除。`return-visit*` 与 `ads.js` 是站点共享/后续接入的独立模块，当前试玩入口不加载广告模块。

## 保存与恢复

新游戏使用 `screw-sort.glass.v1` 保存完成记录，`.round` 保存关卡版本、初始盒数和完整操作日志。旧木质关卡进度不映射到新关卡，但继承英语／印地语与声音偏好。旧中文偏好回退到英语；游戏不再提供中文内容。恢复时逐步重放合法状态转换，包括实际释放角度、被托住的空板及增加盒子/孔位后的当前容量；包含旧清孔操作或第五盒奖励的局面安全回退。版本不符或损坏的局面同样安全回退。本次全部布局更新了版本，因此此前未完成的旧布局不会继续重放；完成记录、解锁进度和偏好保留。新关卡几何/配色变更时需要更新 `version`。

## 生成与测试

校准新增五关并保留前十关：`npm run generate:levels -- --from=11`。校准会比较四个有效配色变体，按参考路线的高压步数比例与贪心收集进度选择方案，检查可解性和跨关梯度后才写入。只比较候选、不写关卡数据：`npm run generate:levels -- --from=11 --inspect-variants`。

仅追加新章节、保留前十关且跳过验证与难度校准：`npm run generate:levels -- --from=11 --skip-validation`。

```sh
npm run generate:levels
npm test
```

浏览器脚本 `tests/browser-smoke.js`、`tests/browser-rewards.js` 为 Playwright CLI 的 `run-code` 函数，使用真实页面点击。只在本地 `qa=1` 时提供只读 `glassDebug.snapshot()` 和等待动画接口，正式域名不开放此诊断接口。

验收记录见 `TESTING.md`。浏览器桌面/触控模拟不替代实体手机测试。
